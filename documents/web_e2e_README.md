# E2E Tests (Playwright)

> Full documentation: [E2E_TESTING.md](E2E_TESTING.md)

Requires the dev server running at http://localhost:3000:

    cd web && npm start

Then in another terminal:

    cd web && npm run test:e2e          # headless
    cd web && npm run test:e2e:headed   # watch mode
    cd web && npm run test:e2e:report   # view last report
